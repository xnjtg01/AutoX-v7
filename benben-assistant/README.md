# 奔奔王国助手 - AutoX-v7 分支

目标平台：MuMu 模拟器内运行的安卓独立 App 版《奔奔王国》。

## 当前交付

- `diagnostic.js`：在 AutoX-v7 中手动运行的环境诊断脚本，检查无障碍、前台包名、截图权限，并将截图保存在模拟器 `/sdcard/BenBenAssistant/diagnostic.png`。
- **目前不是独立 APK，也没有实现自动采集、打野、训练、集结等游戏任务。**
- 不包含上传 APK 的第三方专有脚本或授权机制。

## 测试

1. 在 MuMu 安装适配架构的 AutoX-v7 APK。
2. 开启 AutoX-v7 的无障碍服务。
3. 打开《奔奔王国》并停留在城镇主界面。
4. 在 AutoX-v7 中运行 `diagnostic.js`，按提示授予截图权限。
5. 检查诊断对话框和截图文件。

## 后续开发

在实际游戏截图和包名验证后，再建立屏幕状态识别、任务执行状态机、错误恢复和专用安卓安装包。不能把仅有配置按钮的 APK 当成可挂机成品。
